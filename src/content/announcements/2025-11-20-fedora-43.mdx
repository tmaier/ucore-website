This release used Fedora CoreOS 43.20251024.3.0 and longterm kernel 6.12 for stable. Testing continued to follow the upstream kernel. `mergerfs` and SnapRAID updates were available on both architectures.

Using the longterm kernel favored consistent behavior over the newest hardware support. The announcement called out the need to import the Universal Blue MOK before booting that kernel with Secure Boot enabled.
