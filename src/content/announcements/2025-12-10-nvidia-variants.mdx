The NVIDIA upstream added a 580 LTS repository while the standard repository moved to the open 590 driver. This enabled newer hardware while retaining an LTS choice for Maxwell and Pascal devices.

New `stable-nvidia-lts` and `testing-nvidia-lts` tags carried the LTS driver. The existing `nvidia` tags carried the latest open driver.

Redundant ZFS-specific tags stopped being published. ZFS had already been included in the base images since June 2025. Use the [current image picker](/#images) for supported published tags rather than relying on this historical list.
