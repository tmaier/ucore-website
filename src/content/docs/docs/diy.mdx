Build a derivative image from a published uCore reference. Keep your additions in a Containerfile and use a separate build and signing workflow for your image.

## Start with a published image

import CommandBlock from '../../../components/CommandBlock.astro';

<CommandBlock label="Containerfile" command="FROM ghcr.io/ublue-os/ucore:stable" />

The [Universal Blue image template](https://github.com/ublue-os/image-template) provides a starting point for the build and signing workflow. Choose a full image reference from the [supported matrix](/docs/images/). Your derivative image has its own configuration, publishing, and signing responsibilities.
