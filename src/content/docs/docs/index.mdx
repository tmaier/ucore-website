uCore is an opinionated server operating system built on Fedora CoreOS. These guides cover choosing an image, installing or switching to uCore, and configuring the services included in each image.

## Start here

- [First installation](/docs/first-install/): create a Butane configuration, compile it to Ignition, and install uCore.
- [Existing systems and rebasing](/docs/rebasing/): choose the supported switch or update path for your current deployment.
- [Secure Boot](/docs/secure-boot/): understand kernel and module trust, enroll the Universal Blue key, and check firmware state.
- [Find an image](/#images): select among the explicitly published image references.

## The upstream foundations

uCore is built on Fedora CoreOS but changes the installed software and system behavior. It does not use Zincati for automatic updates and reboots. Use the uCore guides for operating the installed system; these upstream references explain the underlying tools and provisioning platforms.

- [Fedora CoreOS documentation](https://docs.fedoraproject.org/en-US/fedora-coreos/)
- [Butane: writing configuration](https://coreos.github.io/butane/getting-started/)
- [bootc documentation](https://bootc-dev.github.io/bootc/)
