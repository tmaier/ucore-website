`ucore` includes [Distrobox](https://github.com/89luca89/distrobox), which runs a mutable Linux distribution environment alongside the immutable host.

## Interactive tools, not services

Distrobox is useful for interactive tools that are installed conventionally, such as `htop` or `nmap`.

Keep persistent services in containers rather than turning a Distrobox into a host service environment. The `ucore-minimal` image does not include Distrobox; it is part of `ucore` and `ucore-hci`.

See the [container guide](/docs/containers/) for the intended service model and the [image comparison](/docs/images/) for included packages.
