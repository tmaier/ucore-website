Rebasing changes the operating system deployment. Confirm which update manager controls the system and read the [Secure Boot guide](/docs/secure-boot/) before changing to an image with a different kernel.

<Note>Back up persistent data separately. Rolling back an OS deployment does not restore application data, reverse a database migration, or recover deleted files.</Note>

## Select a starting system

The steps depend on whether you are installing a new machine, switching from Fedora CoreOS, or updating an existing uCore deployment. Fedora Atomic desktops and Fedora IoT are unsupported starting points.
